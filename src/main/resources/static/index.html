Зачем этот сайт?

Официальный сайт IThub не охватывает всё — часть информации о колледже разбросана по ВКонтакте, Telegram и другим ресурсам. IT Hub Space собирает всё в единую точку: студенты видят расписание событий, работодатели смотрят портфолио выпускников, абитуриенты узнают о направлениях.
